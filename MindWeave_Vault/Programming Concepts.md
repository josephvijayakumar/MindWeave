# Programming Concepts

Key software engineering principles discussed: Canonical (a chosen design/architecture), Graceful Degradation (system continues with reduced functionality on partial failure), Orthogonal (independent/unrelated components), Atomic (an indivisible operation that fully succeeds or fails completely), Idiomatic (code written in the conventional, natural way for a language), Idempotent (operation can be retried without changing the outcome beyond the first time), and Triage (evaluating and prioritizing issues).
